## 🚀 Featured Research Projects

### 🌧️ Machine Learning-Based Slope Failure Prediction System

- Developed a machine learning-based early warning system for rainfall-induced slope failure using IoT sensor data.
- Processed **43,000+ time-series records** from soil moisture, matric suction, and tilt sensors.
- Implemented **Random Forest, Support Vector Machine, XGBoost, and LSTM** models.
- Built forecasting models for slope movement prediction up to **96 hours ahead**.
- Evaluated model performance using accuracy, precision, recall, F1-score, AUC, RMSE, and MAE.

### 📊 Automated SWCC Computational Modeling Framework

- Built a Python-based computational framework for **Soil-Water Characteristic Curve modeling**.
- Implemented multiple SWCC models, including **Van Genuchten, Brooks-Corey, Fredlund-Xing, Kosugi, Gardner, Campbell, and Haverkamp**.
- Automated data preprocessing, wetting/drying cycle separation, parameter estimation, model fitting, and visualization.
- Designed the framework to support depth-wise hydrological analysis using IoT sensor data.
